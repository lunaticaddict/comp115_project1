# comp115_project1
## Drawing Of A Scenery Using Turtle In Python

Drawing a scenery is a Python project that creates a vibrant landscape using the built-in Turtle library.

## Installation

Since this project relies on Python's built-in `turtle` module, no external package manager installation is required. Just make sure you have Python installed on your system. If you don't have Python on your pc or laptop, you can download it from here: [Python](python.org)

## Concepts
The program demonstrates basic concepts in turtle graphics, including:

* Drawing shapes (circles and lines)
* Using functions to make code
* Simple geometric transformations

## Code Overview
The project is structured around reusable functions:

* `draw_circle(t, x, y, radius, color)` – Draws a filled circle.
* `draw_sun_beams(x, y, color, outer_radius, beam_length, num_beams=12)` – Draws beams around a circle (used for the sun).
* `def draw_rectangle(x, y, width, height, color)`- draws rectangles used to make the house

## How to Run

1. Clone or download this repository.
2. Open the project file `scenery_art.py` in your Python IDE or text editor.
3. Run the program:

```bash
python scenery_art.py
```

4. A window will open showing the scenery.
5. Click anywhere in the window to close it.
